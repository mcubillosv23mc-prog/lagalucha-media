# Plan Auto Eléctrico

App y plan para pasar de un Peugeot 301 diésel a un auto eléctrico sin desordenar las finanzas.

- `app/web/index.html`: la app (funciona también en el navegador).
- `app/android/`: el empaque Android. El APK se descarga del release **plan-auto-latest**.
- `docs/ESTADO_PROYECTO.md`: estado del proyecto, decisiones y avances.
- `.claude/agents/`: subagentes de Claude para cada frente.
